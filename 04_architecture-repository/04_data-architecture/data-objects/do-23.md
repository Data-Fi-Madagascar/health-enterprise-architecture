# DO-23 : Formation sanitaire

Toute structure de soins publique, privée, confessionnelle ou communautaire identifiée de manière unique dans le référentiel national des formations sanitaires. C'est l'unité de base du réseau de soins.

## Rôle et contexte

Ce concept est mobilisé par les capacités [CAP-11](../../03_business-architecture/strategy/capabilities/cap-11.md), [CAP-14](../../03_business-architecture/strategy/capabilities/cap-14.md) et contribue aux flux de valeur [VS-01](../../03_business-architecture/strategy/value-streams/vs-01.md), [VS-02](../../03_business-architecture/strategy/value-streams/vs-02.md), [VS-03](../../03_business-architecture/strategy/value-streams/vs-03.md), [VS-04](../../03_business-architecture/strategy/value-streams/vs-04.md). Il relève du thème « Exploitation & gestion » et est traité dans les chapitres ARTSN [ART-2](../../05_reference-library/patterns/artsn-rules/art-2.md), [ART-4](../../05_reference-library/patterns/artsn-rules/art-4.md).

## Attributs et contraintes

- **Type** : Entité référentielle
- **Contraintes** : Code unique (selon INSTAT) ; dénomination officielle ; type (hôpital, centre de santé, case de santé) ; niveau de qualification ; statut (actif, fermé, en construction)
- **Référentiel source** : Référentiel des formations sanitaires (CAESN)
