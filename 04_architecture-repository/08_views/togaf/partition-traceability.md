# Vue TOGAF - Traçabilité par partition

## Positionnement

Cette vue matérialise la continuité entre le périmètre de gouvernance d'une partition, les flux de valeur, les capacités, les processus métier, les objets de données et les blocs de réalisation. Elle est entièrement dérivée des relations du référentiel canonique et ne constitue pas une seconde source de vérité.

## Chaînes dérivées

Chaque ligne doit se lire de gauche à droite : la partition cadre les flux de valeur, qui mobilisent les capacités et processus, lesquels accèdent aux données et sont soutenus par les ABB ainsi que les SBB ou profils techniques.

## Usage

Cette vue sert aux revues de couverture, à l'analyse d'impact et à l'identification des chaînes incomplètes. Toute correction doit être portée dans le frontmatter de l'objet canonique concerné, puis propagée par le générateur.
