# DO-23 : Formation sanitaire

Toute structure de soins publique, privée, confessionnelle ou communautaire identifiée de manière unique dans le référentiel national des formations sanitaires. C'est l'unité de base du réseau de soins.

## Rôle et contexte

Ce concept est mobilisé par les capacités [CAP-05](../../strategy/capabilities/cap-05.md), [CAP-14](../../strategy/capabilities/cap-14.md) et contribue aux flux de valeur [VS-01](../../strategy/value-streams/vs-01.md), [VS-02](../../strategy/value-streams/vs-02.md), [VS-03](../../strategy/value-streams/vs-03.md), [VS-04](../../strategy/value-streams/vs-04.md). Il est porté par l'objet métier [BO-06 : Exploitation & gestion](../../business/business-objects/bo-06.md) et traité dans les chapitres ARTSN [ART-2](../../../04_patterns/artsn-rules/art-2.md), [ART-4](../../../04_patterns/artsn-rules/art-4.md).

## Attributs et contraintes

- **Type** : Entité référentielle
- **Contraintes** : Code unique (selon INSTAT) ; dénomination officielle ; type (hôpital, centre de santé, case de santé) ; niveau de qualification ; statut (actif, fermé, en construction)
- **Référentiel source** : Référentiel des formations sanitaires (CAESN)
