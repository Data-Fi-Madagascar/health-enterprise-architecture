# DO-25 : Indicateur sanitaire

Mesure standardisée d'une performance, d'un résultat ou d'un processus dans le domaine de la santé. Chaque indicateur doit avoir une définition unique, stable et partagée, avec une méthodologie de calcul précise.

## Rôle et contexte

Ce concept est mobilisé par les capacités [CAP-03](../../strategy/capabilities/cap-03.md), [CAP-08](../../strategy/capabilities/cap-08.md) et contribue aux flux de valeur [VS-01](../../strategy/value-streams/vs-01.md), [VS-02](../../strategy/value-streams/vs-02.md), [VS-03](../../strategy/value-streams/vs-03.md), [VS-04](../../strategy/value-streams/vs-04.md). Il relève du thème « Exploitation & gestion » et est traité dans les chapitres ARTSN [ART-2](../../../04_patterns/artsn-rules/art-2.md), [ART-4](../../../04_patterns/artsn-rules/art-4.md).

## Attributs et contraintes

- **Type** : Entité référentielle
- **Contraintes** : Code unique ; nom ; définition ; méthodologie de calcul ; unité de mesure ; fréquence de collecte ; source de données
- **Référentiel source** : Référentiel des indicateurs sanitaires (CAESN), DHIS2
