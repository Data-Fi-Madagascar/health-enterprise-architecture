# AA-03 — Les applications doivent être interopérables par conception

## Signification

L'interopérabilité ne doit pas être ajoutée après déploiement

## Implications

Toute application expose/consomme des interfaces documentées, sécurisées, conformes à l'Architecture de Référence Technique
