## Contexte

Le cadre d'architecture s'appuie sur plusieurs documents stratégiques nationaux. Leur pérennité est essentielle pour maintenir la légitimité et la cohérence du cadre. Cette note vérifie l'état de ces documents.

## Documents analysés

### 1. PDSS : Plan de Développement du Secteur Santé

| Champ | Valeur |
|-------|--------|
| **Nom** | Plan de Développement du Secteur Santé (PDSS) |
| **Période** | 2020-2024 |
| **Statut actuel** | ⚠️ Potentiellement obsolète (période expirée) |
| **Références dans le cadre** | 23 occurrences |
| **Impact** | Référence principale de planification, 8 axes stratégiques |

**Risque identifié (C9) :** Le PDSS 2020-2024 est potentiellement obsolète, ce qui peut entraîner une perte de légitimité stratégique du cadre.

**Recommandation :**
1. Vérifier si un PDSS 2025-2029 a été adopté
2. Si non, documenter le statut transitoire du cadre
3. Préparer la mise à jour des références si un nouveau PDSS est adopté

---

### 2. SNSD : Stratégie Nationale de Santé Digitale

| Champ | Valeur |
|-------|--------|
| **Nom** | Stratégie Nationale de Santé Digitale (SNSD) |
| **Période** | 2023-2027 |
| **Statut actuel** | ✅ Actif (en cours d'implémentation) |
| **Références dans le cadre** | 26 occurrences |
| **Impact** | 4 axes stratégiques traduits en capabilités numériques |

**Statut :** Le document est actif et couvre la période 2023-2027. Les 4 axes de la SNSD (gouvernance digitale, solutions, ressources, financement) sont lus comme des capabilités numériques transversales.

**Recommandation :** Aucune action immédiate nécessaire. Suivre l'avancement de l'implémentation.

## Impact sur le cadre

Si le PDSS 2020-2024 est confirmé obsolète sans successeur :
- Le cadre reste valide mais perd sa référence stratégique principale
- Les 8 axes stratégiques restent pertinents comme grille de lecture
- Une note de transition doit être ajoutée au document d'ancrage
