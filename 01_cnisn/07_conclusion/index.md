# Conclusion du CNISN


Le CNISN fournit au secteur santé un cadre commun permettant de gouverner les données, services et échanges numériques dans la durée.

Il ne définit pas seulement la manière dont deux systèmes communiquent.

Il définit également :

- qui fait autorité ;
- qui est responsable ;
- quelle finalité justifie l’échange ;
- comment les contrats évoluent ;
- comment les services sont publiés ;
- comment les données sont protégées ;
- comment les divergences sont arbitrées ;
- comment la conformité est démontrée.

Cette approche permet de passer d’intégrations isolées à un écosystème national gouverné, réutilisable, sécurisé et progressivement interopérable.
