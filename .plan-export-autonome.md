# Plan : Documents autonomes à l'export

## Objectif
Rendre chaque fichier Markdown lisible de manière autonome, sans dépendre des autres fichiers du dépôt. Les liens relatifs cassés à l'export sont convertis en texte brut, avec une section « Références » en fin de document.

## Chiffres clés

| Métrique | Valeur |
|----------|--------|
| Fichiers concernés | 106 |
| Liens hors blocs GENERATED | 1 295 |
| Liens dans blocs GENERATED (préservés) | 1 105 |
| Fichiers avec blocs GENERATED | 54 |

## Règles de conversion

### 1. Liens à convertir (hors `<!-- BEGIN:GENERATED -->`)
Tout lien markdown `[label](path)` dont la cible est un chemin relatif (`./`, `../`, `referentiel/`) est converti en **texte brut** :

```markdown
# Avant
Le profil s'appuie sur [CMP-06](../../referentiel/composants/cmp-06.md) et [ART-1](../../referentiel/chapitres/art-1.md).

# Après
Le profil s'appuie sur CMP-06 et ART-1.
```

### 2. Blocs GENERATED préservés
Tout contenu entre `<!-- BEGIN:GENERATED -->` et `<!-- END:GENERATED -->` n'est **pas modifié**.

### 3. Section « Références » ajoutée en fin de document
Après le dernier contenu (avant le frontmatter de fin s'il existe), ajouter :

```markdown
---

## Références

- **CMP-06** — `referentiel/composants/cmp-06.md`
- **ART-1** — `referentiel/chapitres/art-1.md`
- [Index du CNISN](./index.md) → `01_cnisn/index.md`
```

Les références sont dédupliquées et triées par type (identifiant court d'abord, puis chemins).

### 4. Liens de navigation internes
Les liens `./index.md`, `./reading-matrix.md`, etc. dans les fichiers racines (glossary, reading-matrix, acronyms) sont aussi convertis en texte brut + références.

## Approche technique

### Script Python unique (`scripts/export-autonome.py`)

1. **Parcourir** tous les fichiers `.md` dans `01_cnisn/`, `02_artsn/`, `03_ptisn/`
2. **Détecter** les blocs GENERATED (conserver intacts)
3. **Pour chaque lien hors GENERATED** :
   - Extraire le label et le chemin
   - Remplacer `[label](path)` par `label` dans le texte
   - Ajouter le chemin à la liste des références du fichier
4. **Ajouter** la section `## Références` en fin de document
5. **Écrire** le fichier modifié

### Fichiers cibles (106 fichiers)
- `01_cnisn/**/*.md` — ~25 fichiers
- `02_artsn/**/*.md` — ~45 fichiers
- `03_ptisn/**/*.md` — ~45 fichiers
- **Exclu** : `00_caesn/` (déjà autonome), `referentiel/` (fichiers sources)

## Vérification

Après exécution :
```bash
# Vérifier qu'aucun lien relatif ne subsiste hors GENERATED
python3 -c "
import glob, re
for f in glob.glob('0[1-3]_*/**/*.md', recursive=True):
    content = open(f).read()
    gen = [(m.start(), m.end()) for m in re.finditer(r'<!-- BEGIN:GENERATED.*?-->(.*?)<!-- END:GENERATED.*?-->', content, re.DOTALL)]
    for m in re.finditer(r'\[([^\]]*)\]\(([^)]+)\)', content):
        link = m.group(2)
        if not link.startswith(('http', 'mailto', '#')):
            if not any(s <= m.start() <= e for s, e in gen):
                print(f'REMAINING LINK: {f}:{content[:m.start()].count(chr(10))+1} [{m.group(1)}]({link})')
"
```
