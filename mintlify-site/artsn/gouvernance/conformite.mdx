## Pour qui lire ce document

**Niveau :** niveau 3 : Architecture de Référence Technique de la Santé Numérique.

Ce document s'adresse prioritairement aux décideurs institutionnels, aux équipes DEPSI et techniques, ainsi qu'aux équipes SIS, données et suivi-évaluation. Les directions métier et programmes, ainsi que les partenaires techniques et financiers, trouveront une lecture complémentaire utile.

## Objet

Ce document définit les indicateurs et le processus de suivi de la conformité des initiatives numériques aux standards et principes de l'ARTSN. Il permet de détecter les écarts en temps réel et de mesurer l'efficacité de la gouvernance architecturale.

## 1. Indicateurs de conformité

### 1.1 Indicateurs par initiative

| Indicateur | Description | Cible | Mesure |
|------------|-------------|-------|--------|
| **Taux de conformité** | Critères homologation respectés / total | ≥ 90% | Checklist homologation |
| **Nombre d'écarts** | Écarts identifiés lors de l'homologation | ≤ 2 | Rapport d'homologation |
| **Délai de correction** | Temps moyen de résolution des écarts | ≤ 30 jours | Suivi des plans correctifs |
| **Taux de dérogation** | Initiatives avec dérogation / total | ≤ 15% | Registre des dérogations |
| **Taux de régression** | Initiatives ayant perdu leur conformité | ≤ 5% | Audit périodique |

### 1.2 Indicateurs par standard

| Indicateur | Description | Cible | Mesure |
|------------|-------------|-------|--------|
| **Taux d'adoption FHIR** | Initiatives utilisant FHIR / total | ≥ 80% | Registre des initiatives |
| **Taux d'adoption X-Road** | Échanges via X-Road / total | ≥ 70% | Logs X-Road |
| **Taux d'adoption INP** | Initiatives utilisant l'INP / total | ≥ 60% | Référentiel patients |
| **Taux d'adoption RBAC** | Systèmes avec RBAC implémenté / total | ≥ 70% | Audit sécurité |
| **Taux d'adoption audit** | Systèmes avec ATNA / total | ≥ 60% | Audit traçabilité |

### 1.3 Indicateurs globaux

| Indicateur | Description | Cible | Mesure |
|------------|-------------|-------|--------|
| **Conformité moyenne** | Moyenne des taux de conformité initiatives | ≥ 85% | Calcul mensuel |
| **Initiatives conformes** | Initiatives avec conformité ≥ 90% / total | ≥ 75% | Calcul mensuel |
| **Initiatives en risque** | Initiatives avec conformité < 70% | ≤ 10% | Calcul mensuel |
| **Couverture homologation** | Initiatives homologuées / total actives | ≥ 90% | Registre initiatives |

## 3. Processus de suivi

### 3.1 Fréquence

| Action | Fréquence | Responsable |
|--------|-----------|-------------|
| Mise à jour des indicateurs | Mensuelle | DEPSI |
| Revue des écarts | Mensuelle | Comité technique |
| Rapport au CNASN | Trimestriel | Secrétariat CNASN |
| Audit de conformité | Semestriel | CNASN + auditeur externe |
| Revue stratégique | Annuelle | CNASN + Secrétaire Général |

### 3.2 Collecte des données

| Source | Données collectées | Méthode |
|--------|-------------------|---------|
| **Checklist homologation** | Score de conformité par initiative | Formulaires |
| **Logs X-Road** | Trafic inter-systèmes | API monitoring |
| **Référentiel patients** | Utilisation INP | Requête base |
| **Audit sécurité** | Conformité RBAC, ATNA | Rapport audit |
| **Registre initiatives** | Liste des initiatives actives | Base de données |

## 4. Alertes et escalade

### 4.1 Niveaux d'alerte

| Niveau | Condition | Action | Destinataire |
|--------|-----------|--------|--------------|
| **Vert** | Conformité ≥ 90% | Monitoring standard | DEPSI |
| **Jaune** | Conformité 70-89% | Notification + plan corrective | Responsable initiative |
| **Orange** | Conformité 50-69% | Alerte + délai de correction | CNASN |
| **Rouge** | Conformité < 50% | Alerte critique + suspension possible | CNASN + Secrétaire Général |

### 4.2 Escalade

En cas de conformité inférieure à 70%, une notification est adressée au responsable de l'initiative le jour même (J+0). Si aucune action n'est entreprise sous 7 jours, le CNASN est alerté (J+7). En l'absence de correction sous 30 jours, une suspension partielle est décidée (J+30), pouvant évoluer vers une suspension complète sous 60 jours si la situation persiste (J+60).

```
Conformité < 70%  → Notification responsable initiative (J+0)
                   → Alerte CNASN (J+7 si pas d'action)
                   → Suspension partielle (J+30 si pas de correction)
                   → Suspension complète (J+60 si pas de correction)
```

## 5. Rapport trimestriel

### 5.1 Structure du rapport

| Section | Contenu |
|---------|---------|
| **Synthèse** | Nombre d'initiatives, conformité moyenne, tendance |
| **Initiatives conformes** | Liste avec score |
| **Initiatives en écart** | Liste avec écarts identifiés et plans correctifs |
| **Indicateurs standards** | Taux d'adoption par standard |
| **Alertes** | Alertes émises et résolutions |
| **Recommandations** | Actions prioritaires du trimestre suivant |
