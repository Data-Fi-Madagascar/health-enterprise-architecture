## 3. Position nationale

Aucun profil national unique de consentement n’est encore retenu.

**Statut : à instruire.**

## 4. Principe

Le consentement ne constitue qu’une base d’autorisation possible.

Selon le contexte, un traitement peut reposer sur :

- le consentement ;
- le mandat de soins ;
- le mandat de santé publique ;
- une obligation légale ;
- un intérêt vital ;
- un accord interinstitutionnel ;
- une autre base légale documentée.

## 5. Services futurs

- enregistrement du consentement ;
- consultation ;
- retrait ;
- preuve ;
- gestion des finalités ;
- gestion des politiques ;
- vérification au moment de l’accès ;
- traçabilité des décisions.
