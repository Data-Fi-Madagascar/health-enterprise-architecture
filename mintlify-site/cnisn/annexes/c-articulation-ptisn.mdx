Le PTISN doit fournir, pour chaque capacité :

- le service national correspondant ;
- les standards de base ;
- les profils d’échange ;
- les versions ;
- les extensions nationales ;
- les produits candidats ;
- le statut de décision ;
- les preuves de conformité.

Le PTISN ne peut pas modifier un principe du CNISN.

Lorsqu’aucun standard ou profil ne permet de satisfaire une capacité, le PTISN doit :

1.  documenter la lacune ;
2.  identifier les options ;
3.  proposer un profil national ;
4.  soumettre la décision à la gouvernance ;
5.  préserver la neutralité et la réversibilité.
